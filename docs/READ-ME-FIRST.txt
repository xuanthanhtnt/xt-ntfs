XT NTFS — read-write NTFS for macOS
====================================

ENGLISH

1. Install macFUSE first: https://macfuse.github.io/
   Allow its system extension in System Settings > Privacy & Security.
   On Apple silicon Macs, kernel extensions must be allowed in Startup
   Security Utility (the same requirement as Paragon NTFS).
   macOS 26 or later: you can skip the kernel extension. Turn on macFUSE
   in System Settings > General > Login Items & Extensions > File System
   Extensions; XT NTFS then uses macFUSE's FSKit backend (slower).
2. Drag "XT NTFS" onto the Applications folder.
3. XT NTFS is not notarized by Apple. The first time you open it,
   right-click the app and choose Open, or go to System Settings >
   Privacy & Security and click "Open Anyway".
4. In XT NTFS, click "XT NTFS" at the bottom of the sidebar, then
   "Install Engine…". Connect an NTFS disk: it mounts read-write.

Always eject NTFS disks before unplugging them.

TIẾNG VIỆT

1. Cài macFUSE trước: https://macfuse.github.io/
   Cho phép system extension của macFUSE trong Cài đặt hệ thống >
   Quyền riêng tư & Bảo mật. Máy Apple silicon cần bật cho phép kernel
   extension trong Startup Security Utility (giống Paragon NTFS).
   macOS 26 trở lên: có thể bỏ qua kernel extension. Bật macFUSE trong
   Cài đặt hệ thống > Cài đặt chung > Mục đăng nhập & Tiện ích mở rộng >
   Tiện ích hệ thống tệp; XT NTFS sẽ dùng backend FSKit (chậm hơn).
2. Kéo "XT NTFS" vào thư mục Applications.
3. XT NTFS chưa được Apple notarize. Lần đầu mở, nhấp chuột phải vào
   app và chọn Open, hoặc vào Cài đặt hệ thống > Quyền riêng tư &
   Bảo mật và bấm "Vẫn mở".
4. Trong XT NTFS, bấm "XT NTFS" ở cuối thanh bên rồi chọn "Cài engine…".
   Cắm ổ NTFS vào: ổ sẽ được mount ở chế độ đọc/ghi.

Luôn tháo (eject) ổ NTFS trước khi rút ra.

Source code / Mã nguồn: https://github.com/xuanthanhtnt/xt-ntfs
